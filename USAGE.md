# NanoClaw brand usage

Use the project name **NanoClaw** when referring to the open-source project. For its README, documentation, and project artwork, use the supplied assets and follow the sizing, spacing, colour, and typography rules in [BRAND.md](BRAND.md). BRAND.md is the source of truth: if this page and BRAND.md differ, follow BRAND.md.

Choose the light or dark logo to match its background. Use the full logo, with the mascot and wordmark in their supplied proportions, at 32px tall and up. Below 32px, use the wordmark alone. For a square surface, use the app icon. Describe third-party projects and integrations clearly so readers can identify their publisher.

The bundled Inter and JetBrains Mono fonts include their [license files](assets/fonts/). For questions about using the name or artwork outside these examples, open an issue in this repository.
